# NovelistAgent

> 用强化学习模仿任意作家文风，无需微调模型

## 一句话介绍

NovelistAgent 是一个**纯提示工程**的小说生成框架。它通过分析目标作品，自动学习作者的写作风格（句式、节奏、用词偏好等），然后用学到的风格生成新内容。

**核心特点：**
- ✅ 不需要训练模型（零参数更新）
- ✅ 支持任意中文/英文作家风格模仿
- ✅ 内置搜索增强，自动查证历史/地理细节
- ✅ 章节串联生成，保持角色和剧情一致性

## 快速开始

### 1. 安装

```bash
git clone https://github.com/peanut-wu/claw_rl_writer.git
cd claw_rl_writer
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

### 2. 配置 API Key

```bash
cat > .env << EOF
DEEPSEEK_API_KEY=sk-your-key-here
EOF
```

> 获取 DeepSeek API Key：https://platform.deepseek.com/

### 3. 训练（学习文风）

```bash
python3 -m novelist-agent.cli train \
  --novel data/novels/水浒传.txt \
  --config config/deepseek.yaml \
  --steps 10
```

### 4. 生成小说

```bash
python3 gen_series.py --project novels/my_story \
  --idea "你的故事创意" \
  --checkpoint output/checkpoints \
  --config config/deepseek.yaml \
  --prepare

python3 gen_series.py --project novels/my_story --chapters 1-3
```

---

## 工作原理

```
原文小说 → 分割场景 → 提取摘要 → 生成正文 → 评分对比 → 优化提示词 → 循环
```

不看原文怎么写，只看原文写了什么，然后用自己的话复述，再对比差距改进。

## Demo

本项目包含两个完整 Demo，均基于《水浒传》训练集，使用不同 checkpoint 生成不同题材的小说。

### Demo 1: 《龙蛇临安》（训练 5 步）

**输入 Prompt：**

> 主角穿越回南宋末年，发现自己拥有《龙蛇演义》书末王超的武力和技能，而其他人还是普通人。主角拯救华夏的武侠故事

**训练信息：** 5 步训练，best_reward=0.8609

**大纲：** 15 章武侠小说，讲述主角李默在南宋末年凭借龙蛇玄功救国的故事。

**第一章前几段：**

话说当日，临安府御街之上，正是巳牌时分。街面青石板被日头照得泛白，两旁店铺檐下挂着些幌子，有茶坊酒肆，也有绸缎药材铺。行人三三两两，挑担的、推车的、闲逛的，各自忙活生计。忽有一人自巷口转出，布衣草履，身形不甚魁梧，立在那里却如松柏一般。这人神色茫然，举目四望，见那飞檐斗拱、青瓦白墙，又见行人服饰言语，俱是古时模样，心下便是一沉。

他原是异世魂魄，不知怎的归于此身。醒时已在巷中，脑中浑浑噩噩，只记得前尘往事如烟云散去，唯有一身功夫似刻在骨子里。此刻站在御街当口，但觉气血流转，四肢百骸间有股热流奔涌，竟比前世巅峰时还要沛然三分。正自疑惑间，忽听前方喧嚷。

却见三五个泼皮围住一老丈，将那老丈逼到墙角。为首的是个黑胖汉子，敞着怀，露出胸前一片青郁郁的刺花，伸手揪住老丈衣襟道："老杀才，这月的常例钱，今日须得交来！"老丈面色蜡黄，颤声道："上月才交过二两，如何又有常例？"那黑胖汉子冷笑道："如今物价腾贵，二两够甚？须得五两！"

完整内容见 [`demo/longshe-linan/`](demo/longshe-linan/) 目录。

### Demo 2: 《面阵惊清》（训练 10 步）

**输入 Prompt：**

> 主角(现代大学生)穿越到了1639年，获得超能力(可以凭空变出无数方便面)，其余当年和常人一样。主角凭借超能力组织军队抗清。请调用搜索引擎搜索相应历史事件，保证推演合理

**训练信息：** 10 步训练，best_reward=0.9138

**大纲：** 12 章穿越小说，讲述主角陈默在明末凭借方便面超能力抗清的故事。

**第一章前几段：**

陈默睁开眼时，先见着的是灰蒙蒙的天。那云压得低，却又不是要落雨的模样，只是浑浑噩噩地罩着。耳畔嗡嗡地响，辨不清是风声还是人声，只觉着有千百张嘴在张合，又似有千百只手在抓挠。他撑起身子，手掌按下去，触着的不是土，是件硬邦邦、湿漉漉的物事——低头看时，却是半截磨破的衣袖，袖口里探出几根青紫的手指。

他猛地缩手，这才看清周遭。

尸骸。

东一具西一具，横七竖八地摊在道旁野地里。有穿破袄的，有裹草席的，也有赤着上身、肋骨根根可数的。气味混在一处，说不清是腐臭还是焦糊，直往鼻子里钻。远处有烟柱歪歪斜斜地升起来，黑里透着暗红，像是烧了整夜的余烬。

便在这时，掌心一热。他睁开眼，低头看去。右手掌心里，不知何时多了个物事。四四方方，用层油纸包着，约莫巴掌大小。纸是黄褐色，上头印着些红红绿绿的图案，还有几行弯弯曲曲的字——那字他竟认得，是"红烧牛肉面"。

## 配置说明

### 搜索功能

默认使用 DuckDuckGo（免费），可在 `config/deepseek.yaml` 中配置 Tavily / Exa。

### 推理参数

```yaml
inference:
  chapter:
    max_tokens: 4096
    target_words: "3000-5000"
    temperature: 0.8
```

## 常见问题

**Q: 需要多少训练数据？**
A: 10 万字以上效果较好，5 万字也能出基本风格。

**Q: 训练要多久？**
A: 10 步约 30-60 分钟。

**Q: 支持英文吗？**
A: 支持，但针对中文优化。

**Q: 生成的内容会侵权吗？**
A: 不会。训练只学习风格，不复制原文。请使用公版书。
